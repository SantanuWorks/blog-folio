# The Blog-Folio

The Blog-Folio is a combined blogging and portfolio platform. It merges article publishing, project showcasing, and static pages into one cohesive and structured web experience. The platform focuses on clarity, modularity, and a clean content workflow.

---

## Overview

The Blog-Folio includes:

- A blog system for writing and publishing posts
- A portfolio section for showcasing work and projects
- A consistent UI built with Tailwind CSS and Vue components
- A Laravel backend providing API endpoints and content logic
- A MySQL database for structured and scalable data management

---

## Features

### Blog
- Markdown-friendly posts  
- Categories, tags, and featured posts  
- Reader-friendly layout  
- SEO-ready metadata

### Portfolio
- Project listings with images and descriptions  
- Dedicated project detail pages  
- Tag-based filtering  
- Support for case studies and long-form writeups

### Design & UI
- Responsive and mobile-first  
- Vue component-driven architecture  
- Tailwind CSS utility styling  
- Simple and adaptable theming

### System
- Laravel-powered backend  
- REST-style API endpoints  
- Vite-based build system  
- MySQL database structure

---

## Tech Stack

| Layer      | Technology   |

| Frontend  | Vue.js       |
